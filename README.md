# 🛒 BazarDor | বাজার দর

**Know the prices of essential products in Bangladesh at a glance.**

BazarDor is a web application that helps users explore and compare the prices of everyday essentials in Bangladesh. It provides product pricesand market-wise information to help users stay informed about daily market changes.

## 🌐 Live Demo

https://bazardorbangladesh.vercel.app/

## 🛠️ Technologies Used

- **Next.js** — Application framework
- **React** — User interface development
- **TypeScript** — Type-safe development
- **Tailwind CSS v4** — Responsive styling
- **Better Auth** — User authentication
- **MongoDB** — Database
- **Lucide React** — Icons
- **BazarDor API** — Product and price data ( https://openapi.programming-hero.com/api/bazardor)

## ✨ Key Features

1. **📊 Daily Price Tracking:** Explore the latest prices of essential products in Bangladesh.
2. **🏷️ Category-Based Browsing:** Browse products by category and sort them by price.
3. **🏪 Market-Wise Price Information:** Compare product prices across different local markets.
4. **🔐 Protected Product Details:** Sign in to access detailed product information through protected routes.
5. **🔐 User Authentication:** Sign up, sign in, manage profile information, and sign out securely.
